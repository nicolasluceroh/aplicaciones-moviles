## Cómo usar las tarjetas
Cada tarjeta debe tener:
- Título concreto.
- Responsable.
- Descripción corta de qué debe quedar funcionando.
- Checklist de 3 a 6 puntos.
- Rama de Git.
- Link al Pull Request cuando exista.
- Requisitos relacionados (RF) cuando corresponda.

## Trabajo anterior
Las tareas que ya se realizaron en el primer MVP pueden agregarse a **Hecho**, siempre basadas en trabajo real. Usar los commits y PR existentes como referencia; no inventar fechas ni tareas.
