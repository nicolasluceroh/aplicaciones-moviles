# Documentación técnica - Pilar de Sonrisas

Esta carpeta reúne la documentación funcional y técnica de la versión actual del proyecto.

## Contenido

- `00-proyecto.md` - descripción, alcance y tecnologías.
- `01-requisitos.md` - requisitos funcionales y no funcionales.
- `02-home-ui.md` - Home y componentes de interfaz.
- `03-catalogo-productos.md` - catálogo, búsqueda y detalle de producto.
- `04-carrito-donacion.md` - carrito, checkout y confirmación.
- `05-cuenta-fundacion.md` - cuenta, autenticación y módulo de fundación.
- `06-arquitectura-integracion.md` - navegación, contextos e integración.
- `07-base-de-datos.md` - tablas, seguridad y migraciones de Supabase.
- `08-pruebas.md` - casos de prueba funcionales.
- `img/` - capturas utilizadas como evidencia visual.

La documentación debe reflejar el comportamiento que existe en `main`. Los archivos de migración de Supabase se encuentran en `supabase/migrations/`.

- `09-comercios.md` - login de comercios, ofertas según necesidades, SQL, RLS y pruebas.
